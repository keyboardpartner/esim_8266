Uploader Help

Quick reference for file upload, stream/config actions, and serial commands.

Web Upload

  • Select a file and start address, then click Upload and stream. Supported picker extensions: .bin, .bit, .rom.
  • Files are staged in LittleFS first; .bin and .rom files are automatically streamed to device via SPI. FPGA configuration (.bit) files are sent to FPGA via JTAG (start address not relevant here).
  • You may also upload .html or .css files. These are not streamed, but stored in LittleFS as well.
  • You can later run actions from the file table.

File Table Actions

  • Stream: sends normal data files to the selected target starting at the given address.
  • Config: appears for .bit files and configures the FPGA via JTAG.
  • Delete: removes the file from LittleFS.
  • A click on the file name will offer it for download.

Serial Commands

  • c: configure FPGA with staged file (JTAG build).
  • d: hexdump 256 bytes from device.
  • e: erase device memory.
  • h: print status and help text.
  • i: print current file/debug info.
  • r: replay current staged file.
  • j<filename,start,len><CR>: dump EPROM to file.
  • u: framed serial upload.

Troubleshooting

  • For MOJO-like FPGA boards, ensure the bitstream "fpga_main.bit" is present in file system. The bitstream is loaded into the FPGA during startup configuration via JTAG.
  • If upload fails, verify LittleFS is mounted and free space is available.
  • If streaming/config fails, check file exists and is non-empty.
  • If Wi-Fi mode falls back to AP, verify STA credentials.
