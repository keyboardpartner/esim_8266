Uploader Help

Quick reference for file upload, stream/config actions, and serial commands.

Web Upload

Select a file and start address, then click Upload and stream.

Supported picker extensions: .bin, .bit, .rom.

Files are staged in LittleFS first. You can then run actions from the file table.

File Table Actions

  • Stream: sends normal data files to the selected target starting at the given address.
  • Config: appears for .bit files and configures the FPGA via JTAG.
  • Delete: removes the file from LittleFS.

Serial Commands

  • h: print status and help text.
  • i: print current file/debug info.
  • r: replay current staged file.
  • c: configure FPGA with staged file (JTAG build).
  • e: erase device memory.
  • u: framed serial upload.
  • d<filename,start,len><CR>: dump EPROM to file.

Troubleshooting

  • For MOJO-like FPGA boards, ensure the correct bitstream "fpga_main.bit" is present in file system. The bitstream is loaded into the FPGA during startup configuration via JTAG.
  • If upload fails, verify LittleFS is mounted and free space is available.
  • If streaming/config fails, check file exists and is non-empty.
  • If Wi-Fi mode falls back to AP, verify STA credentials.
